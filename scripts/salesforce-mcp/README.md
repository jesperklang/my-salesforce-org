# Salesforce MCP Editor Configuration Sync

This script keeps local editor configuration in sync with the Salesforce Model Context Protocol (MCP) server. It updates the `@salesforce/mcp` package, reads the tool configuration from its folder, and writes MCP server settings for supported editors. This lets you use your LLM of choice instead instead of Agentforce Vibes.

At a high level, the script:

- updates the local `@salesforce/mcp` dependency with npm;
- reads `scripts/salesforce-mcp/vibes-mcp-to-editor.jsonc` for telemetry, usage of none-GA tools and filtering preferences;
- builds an editor MCP server configuration for Salesforce tools;
- writes or updates the MCP server configuration files using [Salesforce's MCP documentation](https://developer.salesforce.com/docs/atlas.en-us.sfdx_dev.meta/sfdx_dev/sfdx_dev_mcp_get_started.htm) in editor-specific settings:
  - `.vscode/mcp.json` for VS Code.
  - `.cursor/mcp.json` for Cursor.

The script is useful when you want to make sure you use Salesforce's current best practices, since these can change over time.

## Usage

- Add `"upsert:salesforce-mcp": "node scripts/salesforce-mcp/sfdx_mcp_to_vscode.ts"` to your `package.json` scripts.
- Run the command:

```bash
npm run upsert:salesforce-mcp
```

The command may update `package.json` and `package-lock.json` because it runs an npm update for `@salesforce/mcp` to make sure you get the latest toolsets and tools. It may also create or change editor-specific MCP configuration files.

## Configuration

The script reads `scripts/salesforce-mcp/vibes-mcp-to-editor.jsonc`.

Supported options:

- `sendTelemetry`: enables or disables telemetry for the generated Salesforce MCP server configuration.
- `useNoneGATools`: controls whether non-General Availability Salesforce MCP tools are included.
- `ignoreToolsets`: excludes complete Salesforce MCP toolsets by name.
- `ignoreTools`: excludes individual Salesforce MCP tools by name.

Review this configuration before running the script if your project has strict requirements around telemetry, preview tooling, or which MCP tools should be available to AI agents.

## Notes

- The script has mainly been generated by an LLM, but has been reviewed, read, and edited by the maintainer. There could be some mistakes or room for improvement, so please review the code before running it.
- The code has only been tested using VS Code, so if you are using a different editor or IDE, there might be some adjustments needed to run the script successfully.
- The script currently targets only VS Code and Cursor MCP configuration files.
